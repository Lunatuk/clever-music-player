Скачивание пакета 48 на Windows подтверждено пользователем. Различия тегов
существующих файлов не исправляются. В этом пакете новое поведение на Android:
папка назначения и проверка внутреннего временного хранилища. Полная загрузка
песен на телефоне пока не включена; Windows достаточно оставить на версии 48.

1. Установи APK 49 поверх прежней версии без удаления данных. Открой Яндекс
   Музыку, прокрути до «Хранилище загрузок» и нажми «Проверить временное
   хранилище». Должно появиться сообщение об успешной проверке и удалении
   тестовых данных. Можно повторить один раз.
2. Нажми «Выбрать папку загрузок» и выбери обычную папку во внутренней памяти,
   например Music/Загрузки плеера. Разреши доступ через системный диалог.
   Имя должно сохраниться; «Проверить доступ» должно подтвердить возможность
   создания файлов. Полностью закрой/открой плеер и проверь сохранённый выбор.
3. Повторно открой выбор и отмени его: прежняя папка должна остаться. Затем
   «Сбросить выбор» должен убрать назначение, сохранив музыку и прежние папки
   библиотеки. Достаточно запустить один трек и проверить обычное воспроизведение.

Эти действия не сканируют музыку, не скачивают её и ничего не записывают
в выбранную папку. Право записи проверяется по grant/возможностям провайдера;
фактическая публикация песни будет следующим отдельным шагом.
Физические ENOSPC, потеря доступа в ходе загрузки и crash recovery ещё впереди.

**Пакет 48 — доступное качество, M4A и подпись папки**

Исправлены label/hint пустой папки на реальной теме приложения. Добавлен M4A.
MP3/M4A запрашивают лучшее доступное качество и принимают NQ192 вместо отказа
из-за прежнего требования HQ320. Поддержана потоковая доставка encraw.
FLAC остаётся только lossless: проверенный выбранный трек Яндекс отдаёт
в NQ192, поэтому для него нужны MP3/M4A. Подписка сама по себе не гарантирует
любой формат каждого трека. Из lossy не создаётся фиктивный FLAC.

Живые MP3 и M4A уже проверены: реальная загрузка выбранного трека,
расшифровка и полное декодирование. Тестовые файлы удалены; библиотека не менялась.
Повторно проверять VPN, входить, пересканировать или копировать музыку не нужно.

1. Закрой предыдущий плеер, распакуй Windows ZIP 48 целиком. В настройках
   Яндекса проверь подписи полей и сохрани прежнюю тестовую папку.
2. Оставь небольшой плейлист из 1–3 треков, лимит 3. Выбери MP3 либо M4A,
   запусти «Обновить библиотеку». Проверь появление трека с обложкой и его звук.
3. Повтори тот же полностью скачанный плейлист: дублей в том же формате
   быть не должно. Смена формата — отдельная загрузка, существующие файлы
   не перекодируются. При повторе ранее неудачного задания того же профиля
   включи флажок повтора; уже добавленные треки останутся на месте.

Если ошибка сохранится, создай новый диагностический отчёт: теперь он покажет
возвращённые формат/качество/битрейт и точную категорию отказа, без ключей и URL.
Android 48 — совместимая сборка, скачивание на телефоне пока не включено;
для проверки этого исправления обновлять телефон не обязательно.

**Пакет 47 — кнопка обновления библиотеки из Яндекс Музыки**

На Windows теперь доступна загрузка из «Мне нравится» и выбранных плейлистов:
папка назначения, MP3 320/FLAC, лимит, прогресс и остановка. По умолчанию —
3 попытки за запуск. Android пока сохраняет подключение и проверку коллекций;
скачивание на телефоне будет отдельным этапом.

Для первой проверки используй небольшой отдельный плейлист из 1–3 доступных
треков, временно сними «Мне нравится» и остальные плейлисты. Повторно вводить
токен, копировать или пересканировать существующую фонотеку не нужно.
Старые файлы, скачанные вне плеера, пока автоматически с ID Яндекса не
сопоставляются. Защита от повторной загрузки действует для файлов,
зарегистрированных этой системой загрузки; один заголовок не считается совпадением.

1. Закрой прежний плеер. Распакуй Windows ZIP 47 целиком и запусти EXE.
   Создай пустую папку для проверки и добавь её в разделе библиотеки.
   В настройках Яндекса выбери её, MP3 320 (или FLAC) и лимит 3.
   Нажми «Обновить библиотеку»: должны появиться этапы и затем до 3 треков
   с названиями, исполнителями и встроенными обложками. Проверь воспроизведение
   одного трека. Недоступный вариант качества должен дать понятную ошибку.
2. Повтори обновление того же полностью скачанного маленького плейлиста.
   Повторных файлов/записей появиться не должно. Для большой коллекции
   следующий запуск продолжает оставшиеся задания в пределах лимита.
3. Если есть ещё нескачанный трек, начни обновление и нажми остановку.
   Управление должно вернуться, уже добавленное сохраняется. Для повтора
   отменённого задания включи «Повторить неудачные и отменённые загрузки»
   и запусти снова. Уход со страницы сам по себе обновление не останавливает.
4. Перезапусти плеер: папка, качество и лимит сохраняются; скачивание
   автоматически не начинается. После проверки можно вернуть обычный выбор
   коллекций и увеличить лимит. Лучше сначала подтвердить маленькую загрузку.

При ошибке сохрани диагностический отчёт. Токен присылать не нужно.
На Android 47 достаточно при желании проверить прежнее воспроизведение и
страницу Яндекса: видны аккаунт/коллекции и пояснение о загрузке на Windows.
Устанавливать Android 47 для проверки Windows-загрузки не требуется.

Автоматически проверены синтетические API/CDN, реальная обработка MP3/FLAC,
теги/обложки/импорт, повтор без скачивания, отмена/повтор и интерфейс.
Живая авторизованная загрузка с пользовательским аккаунтом ещё не проверена.

[Контракт и границы](architecture/yandex-library-update-ui.md).

**Пакет 41 — запуск звука и порядок громкости переходов**

Пакет 40 подтверждён пользователем на Windows и Android. В 41 исправлены
параллельные Play/снятие нулевой громкости и запоздалые команды fade.
Громкость подтверждается после открытия источника и перед Play/resume.

**Пакет 39 — диагностика подключения к Яндексу**

**Пакет 38 — подключение Яндекса и выбранные коллекции**

Пакет 37 подтверждён пользователем. Windows ZIP распаковать целиком в новую
папку, предварительно закрыв плеер. APK 38 можно установить поверх preview
без удаления. Пересканирование и копирование музыки не нужны.

1. Windows: Настройки → «Яндекс Музыка» внизу. Android: новая кнопка с облаком
   в верхней панели библиотеки. Вставить существующий OAuth-токен из своего
   загрузчика или callback ссылку с access_token. «Как получить токен» открывает
   инструкцию в браузере. Вводить секрет только в приложении, в чат не присылать.
   Нажать «Подключить»: должны появиться имя аккаунта, «Мне нравится» и свои
   плейлисты. При первом входе выбрано только «Мне нравится».
2. Выбрать один знакомый плейлист, нажать «Проверить выбранные коллекции».
   Должны появиться счётчики состава. Это позиции с повторами, не число
   скачиваний: скачивание включим следующим этапом. Если сеть отключена,

   Повторный вход должен сохранить выбор плейлистов. На Android особенно
   полезны проверка после полного закрытия/перезапуска и выход.

Достаточно короткой проверки этих действий; полный тест библиотеки не нужен.
