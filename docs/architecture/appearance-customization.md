## Общие параметры вместо отдельных палитр экранов

`appearance/appearance_settings.dart` содержит переносимую модель без Flutter:

| Параметр | Диапазон | Исходное значение |
| --- | --- | --- |
| Тема | Как в системе / светлая / тёмная | Тёмная |
| Акцент | RGB; пять готовых цветов или HEX RRGGBB | FFCC33 |
| Анимации | Выключены / плавные / обычные / быстрые | Обычные |
| Плотность | Обычные / компактные строки | Обычные |
| Скругление обложек | 0–24 | 8 |

`appearance_theme.dart` строит ThemeData/ColorScheme и ThemeExtension
AppearanceTokens: семантические цвета, контрастный текст на акценте, отступы,
скругление и длительности. Экран отвечает за композицию, параметры берёт из
темы. Новые настройки добавляются в модель/декодер, редактор и соответствующий
токен; экран не должен заводить независимую копию палитры. Параметры шрифта,
произвольные схемы размещения и редактор каждой детали пока не предоставляются.
Заголовки/размеры текста соблюдают системный масштаб, не заменяют его настройкой.

Цвета фона/текста/второстепенных подписей выводятся из светлой или тёмной темы.
Акцент применяется к кнопкам, выделениям и графике; основной текст не окрашивается
пользовательским цветом без проверки контраста. Чёрный/белый текст на самом акценте
выбирается по относительной яркости; ColorScheme получает отдельные читаемые
цвета интерфейса. Тёмная, светлая и крайние акценты проверены на контраст.

## Сохранение и жизненный цикл

AppearanceController использует существующий SettingsRepository и один JSON
`appearance.v1` с `version:1`; схема БД13 не меняется. Отсутствующая/повреждённая,
слишком длинная запись или неизвестная версия дают безопасные исходные значения
без автоматической перезаписи. Неверное отдельное поле восстанавливается отдельно;
RGB ограничен24 битами, скругление0–24. Другие настройки/музыка не затрагиваются.

Изменение визуально применяется сразу; полные снимки настроек записываются
последовательно. Запоздалая загрузка не перекрывает явный выбор пользователя;
ошибка прежней записи не перечёркивает более свежую успешную. Ошибка сохранения
видна с повтором, тексты исключений не показываются. close прекращает приём
изменений и ждёт начатые чтение/записи перед закрытием БД. После закрытия или
dispose уведомления не отправляются. Контроллер без repository изолирован в памяти.

## Движение и производительность

Плавные/обычные/быстрые длительности имеют множители1.5/1/0.65; выключение даёт
нулевую длительность. Системный disableAnimations имеет приоритет. Новые маршруты,
смена страниц демо, пример в настройках и смена темы используют общий механизм.
Старые маршруты также отключают визуальный переход при reduced motion; их базовая
скорость и внутренние анимации стандартных Material-виджетов не объявляются
полностью перенастроенными. Звуковой crossfade не связан с этими параметрами.

Графика «Волны» — ограниченный CustomPainter в RepaintBoundary, без фонового
тикера, видео/сетевых ресурсов и полного декодирования изображений. Списки остаются
ленивыми, обложки ограничены размером. Компактность сохраняет штатные области
нажатия. Вёрстка проверяется на320px/200% тексте и landscape.

## Что подключено в62

На настоящем Android появился «Внешний вид» (значок палитры): общая тема,
сохранение, цвета, плотность, скругление старых обложек. «О версии» → «Варианты
дизайна» показывает новую компоновку с теми же параметрами оформления, но с демо
музыкой/очередью. Его кнопки не управляют реальным плеером. Новая навигация,
избранное, плейлисты и экраны очереди на настоящих данных подключаются далее.
Windows51 остаётся рабочей версией; desktop нового дизайна пока доступен в галерее.

HTML-галерея содержит16 настоящих Flutter-снимков (две темы × четыре экрана ×
две компоновки), офлайн. Это снимки, интерактивное демо находится в APK62.
Макеты служат основой для следующих экранов, кода воспроизведения они не заменяют.
