GNU Make 4.4.1 is only a developer build tool. Its unmodified source archive
(GPLv3 or later, license inside) is provided to reproduce the build; its
executable is NOT included in this runtime distribution. MSVC and Git Bash
are developer prerequisites, not included and not required on the user's PC.
Windows system libraries and the static MSVC runtime supply OS/C services.

Rebuild on Windows x64 with Python 3.11+, Git Bash and a complete Visual C++
2019 16.8+ installation (C11 support). Unpack/copy sources/ to an ASCII path.
Example, in that directory (choose unused work/output paths):
  python build_media_helper.py --work-dir C:/cmp-build --output C:/cmp-helper --source-cache .
Optional --vcvars selects VC/Auxiliary/Build/vcvarsall.bat explicitly.
No external pip packages or music/account access are used. Built files are
checked by tool/check_bundled_media_helper.dart in the application repository.
Production processing only copies compressed audio; PCM is decoded for proof.
